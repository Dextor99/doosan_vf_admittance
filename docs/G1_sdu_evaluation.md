## 从当前源码确认的接口与限制

- `AdmittanceControllerPosition(double frequency=500.0)` 在构造时将 `dt_` 固定为 `1/frequency`；每次 `step()` 不接收实际 `dt`。可以指定名义频率，但不能直接反映运行时抖动或偶发延迟。
- 平移和姿态分别使用 `3×3` 质量、阻尼、刚度矩阵；这不是任意耦合的 `6×6` wrench/twist 内核。
- 输入位置参考为米，输入姿态四元数顺序为 `[w,x,y,z]`。输出为绝对位置和四元数；内部积分位置误差后计算 `x_desired + x_e`，不是单纯输出偏移。
- `reset()` 清零平移/角速度与位移状态，并把姿态误差四元数重置为单位四元数。
- 当前源码用显式的 `dt` 更新加速度后先更新速度，再用新速度更新位置。输出没有看到面向本项目工作区/速度/加速度的安全限幅；这些仍必须由独立监督器负责。
- 默认参数为位置 `M=22.5`、`D=70`、`K=0`，姿态 `M=0.25`、`D=3`、`K=0`；与旧工程的 `M=1`、`D=12` 及每轴任务配置不能直接视为等价。

## 构建前提

本地 CMake 文件声明 CMake 3.16、C++17，并通过 `FetchContent` 下载 Eigen 3.4 和 yaml-cpp 0.9。默认还会启用测试、示例、文档和 Python 绑定；不需要的功能应在独立构建目录中明确关闭。测试和 Python 绑定需要 `ext/Catch2`、`ext/nanobind` 子模块。当前主机没有 CMake，尚未开展干净构建；本记录不声称上游构建成功。

## 当前结论和下一步

暂不将 SDU 接入新工程或任何机器人命令链。选型需要先获得带 commit 的上游 checkout，做独立构建与许可证/依赖记录，再用 50 Hz 名义输入和实际 `dt` 抖动回放，对照旧单轴、三轴与定点模型，明确误差和偏移语义。若固定步长限制无法满足需求，再比较自研可变 `dt` 内核；两种控制器不能同时参与正式运动。
