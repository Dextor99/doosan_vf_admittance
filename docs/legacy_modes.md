# 旧工程功能基线

来源：`legacy-baseline/doosan_ft_calibration_cpp` 的 README、设计说明、控制器头文件和四个 `ft_admittance_*.cpp`。这是源码盘点，不代表当前仍适合在实机运行；旧程序保持为历史参考。

## 共用定义

- Doosan `servol()` 位置命令；旧程序使用约 20 ms 的外层周期，并用单调时钟测量每次实际 `dt`。周期不是硬实时保证。
- 内部导纳计算以米、秒、牛顿为单位；机器人 SDK 位姿边界使用 mm/deg。末端姿态固定。
- XJC 补偿后力被转换到基座系。进入控制前记录力零点，运行中检查机器人和传感器数据新鲜度、报警、关节范围和外力模长。
- 默认力限值在不同程序间不一致；X 单轴程序源码默认值为 200 N，XYZ/回归/轨迹程序默认值为 20 N。命令行允许配置。它们是旧软件保护阈值，不是经风险评估的接触安全限值。
- 用户停止时请求慢速停止；程序异常时尽力请求快速停止。通信中断等情况下 SDK 停止请求不保证成功。
- 启动前检查机器人为 REAL 系统且处于 `STANDBY` 或普通 `SAFE_OFF`；取得控制权并等待安全状态 `SW_RUN/CW_RUN`。启动前合力小于 `0.5 N`，控制权准备后还检查 TCP/关节位置未明显移动。
- 运行时机器人反馈与 XJC 样本各自必须不超过 `100 ms`；控制循环超过计划周期 `40 ms` 会退出。四个模式均监控关节限位和姿态偏差 `2°`，但当前代码只在监视模式显示机器人/传感器采样时间差，并未对运行时两者的相对采样时间差设独立阈值。

## 模式清单

| 程序 | 柔顺轴与参考 | 旧参数/约束 | 松手后的预期行为 |
|---|---|---|---|
| `ft_admittance_x` | 基座 X 单轴，进入时以当前 TCP X 初始化；Y/Z/姿态保持 | `M=1 kg`、`D=12 N·s/m`、`K=0`、死区 `0.25 N`、滤波 `0.08 s`；导纳速度/加速度分别限制为 `30 mm/s`、`150 mm/s²`。SDK 跟随上限 `50 mm/s`、`300 mm/s²`。另有 X 跟踪误差 `12 mm`、Y/Z 漂移 `3 mm` 检查 | 阻尼减速后停在新 X 位置 |
| `ft_admittance_xyz` | 基座 XYZ 平移；进入时锁定姿态并以当前 TCP 初始化 | 与 X 模式相同；SDK 跟随上限 `50 mm/s`、`300 mm/s²`；导纳加速度和速度是三轴合向量上限。没有程序 TCP 行程边界；跟踪误差只记录 | 阻尼减速后停在新 XYZ 位置 |
| `ft_admittance_xyz_return` | XYZ 平移，进入时记录固定 home 点；姿态保持 | `M=1 kg`、`D=12 N·s/m`、`K=36 N/m`、死区 `0.25 N`、滤波 `0.08 s`；导纳 `30 mm/s`、`150 mm/s²`；SDK 跟随上限 `50 mm/s`、`1000 mm/s²`。没有程序 TCP 行程边界；跟踪误差只记录 | 回到 home 点 |
| `ft_admittance_y_trajectory` | 基座 Y 往返参考轨迹，叠加 XYZ 定点回归导纳偏移；姿态保持 | 导纳参数与 XYZ 定点回归相同；单程 `200 mm`，每个往返周期总路径 `400 mm`；速度 `20 mm/s`、加速度 `50 mm/s²`；SDK 跟随上限 `50 mm/s`、`1000 mm/s²`。轨迹周期性重复 | 导纳偏移收敛后仍沿参考轨迹运行；轨迹终止/停止行为需按源码流程退出 |

## 迁移注意

- 当前源代码在复用传感器和 DRFL 的同时，四个程序各自拥有设备连接、循环和停止逻辑。新系统应迁移参数化任务，不并行启动多个命令发送程序。
- 命令行均接受 `<ip> <serial-device> <model.txt> --monitor`；运动模式为 `--run` 后接一个 X 或三个 XYZ 方向符号（取 `1/-1`），可选 `--force-limit-n <1..200>`。符号需在现场逐轴核验，不能把示例值当默认安全配置。
- 旧采集 CSV 的姿态字段为 `[qx,qy,qz,qw]`，新数据契约为 `[w,x,y,z]`；迁移数据时必须显式重排。旧 `servol()` 边界使用 mm/deg，新工程内部使用 m/rad。
- XJC 的序列、单位、轴向和符号仍需依厂家协议及逐轴静态检查闭环确认；旧程序的候选解释不能作为已认证传感器定义。
- 旧程序里没有 X/Y/Z 软件 TCP 工作区边界。旧力阈值、跟随上限和导纳限值只用于理解已有行为，不能直接继承为新平台或接触实验的安全参数。
- `trajectory_y` 的当前实现是单程 200 mm（每个往返周期 400 mm）并叠加 XYZ 恢复偏移；README 中“Y 轨迹抗扰”这个简写不意味着完整轨迹实验数据已经归档。
