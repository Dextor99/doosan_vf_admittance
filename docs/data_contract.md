# 初版数据契约

当前仅定义离线骨架使用的数据类型。设备驱动、传感器解码和运动闭环尚未实现。

## 单位和表达

- 位置：米；线速度：米/秒；关节位置：弧度。
- 姿态：单位四元数，字段顺序为 `[w, x, y, z]`。
- 力：牛顿；力矩：牛顿米；角速度：弧度/秒。
- `PoseReference::frame` 默认表示基坐标系下的参考。任何其他坐标变换都必须由显式变换模块完成。

## 时间和有效性

- `MonotonicTime` 使用主机 `steady_clock` 时钟域，不能与墙上时钟或设备时间直接比较。
- 每个设备样本保留采样/接收时间；控制循环另外传入实际测得的 `dt_seconds`。
- `valid`、`connected`、`motion_allowed` 和 `compensated` 是独立标志。字段存在或数值为零不代表样本有效。

## Wrench 的坐标系和作用点

`WrenchSample` 同时要求坐标系和参考点。不得把传感器原点的力矩当成 TCP 原点力矩；力矩移点和坐标旋转应由之后的显式变换实现，并以解析用例确认后再进入控制链。

## 结构体

当前 C++ 定义在 `include/vf_control/core/types.hpp`。若字段语义变化，应同步更新本文件和数据版本记录。
